Space Rangers HD: A War Apart 简体中文语言包 v1.0

适用版本：Windows / Steam 英文版 2.1.2500。
无需安装 Python 或其他运行环境，使用 Windows 自带 PowerShell。
请先在 Steam 游戏属性中将语言设为 English，并完成游戏下载。

安装
1. 将 ZIP 完整解压到任意本地文件夹，不要直接从压缩包中运行。
2. 退出游戏，双击 Install.bat。
3. 安装器自动寻找 Steam 游戏目录。找不到时，粘贴包含 Rangers.exe 的目录。
   可在 Steam → 游戏 → 管理 → 浏览本地文件中查看该目录。
4. 看到“安装完成”后，从 Steam 启动游戏即可。
   如果提示没有写入权限，右键 Install.bat → 以管理员身份运行。

语言切换与模组
安装会启用“简体中文语言包”，保留其他模组选项，取消德语/西班牙语语言包。
在游戏开始菜单 → 模组中，可以勾选或取消中文语言包；确认并重启游戏后生效。
切回英语后，菜单、成就、模组名称/介绍也随之回退。
本包沿用官方语言模组机制，保留 Steam 成就统计与解锁逻辑。
不要同时启用多个语言包。其他改变资源的第三方模组兼容性尚未逐一测试。

包含内容
完整译文共 56,396 条，含界面、对话、新闻、成就及 80 个文字任务资源。
包含中文字体、长文本换行、设置标签和模组界面语言切换修复。
不改动任务条件、战斗、奖励与其他玩法数据，不修改或删除存档。
已有存档中已生成的新闻、名称等文字可能保留创建时的语言。

卸载
退出游戏后，双击 Uninstall.bat，选择同一游戏目录。
原文件备份位于游戏目录的 .srhd-zh-backup 中，请勿删除。
卸载后备份仍保留。安装后若改变了模组选项，卸载仅移除中文选项，保留其他选择。
如果游戏更新、其他补丁或 Steam 文件验证改变了已安装文件，卸载器会停止，
防止用旧版本文件覆盖更新后的游戏。此时可通过 Steam 验证文件恢复原版；
随后在模组页面停用中文语言包。游戏新版本需要另行制作兼容补丁。

注意
本包只接受匹配的原版文件，发现未知版本或其他汉化覆盖时会停止且不改动游戏。
已有旧测试汉化的玩家请先恢复原版，再安装此分发版本。
请勿把本包与旧版覆盖式汉化混合使用，也勿删除原始备份。
这是当前游戏实测版本的首个分发包；完整流程仍欢迎玩家反馈遗漏和显示问题。
包含的游戏程序修复采用增量补丁，需合法拥有原版游戏；本包不包含完整游戏。

命令行（可选）
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Installer.ps1 -Mode Install -GamePath "游戏目录" -NonInteractive
将 Install 改为 Uninstall 可卸载，改为 Verify 可只校验而不修改游戏。
