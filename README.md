# Space Rangers 简体中文汉化

适用于 **Space Rangers HD: A War Apart / Steam 英文版 2.1.2500** 的简体中文语言模组与自动安装包。

## 下载与安装

前往 [Releases 下载页](https://github.com/abstracts333/-/releases/latest)，下载 v1.0 的安装 ZIP。

1. 在 Steam 游戏属性中选择 **English**，退出游戏。
2. 完整解压安装 ZIP，双击 **Install.bat**。
3. 安装器自动识别 Steam 库；找不到时输入包含 `Rangers.exe` 的游戏目录。
4. 安装完成后从 Steam 启动游戏。

无需 Python，使用 Windows 自带 PowerShell。写入权限不足时右键安装器，选择“以管理员身份运行”。

## 功能

- 56,396 条校对译文，覆盖界面、对话、新闻、成就及 80 个文字任务资源。
- 中文字体与长文本自动换行，以及设置标签、模组信息显示修复。
- 可在游戏的模组菜单中启用或停用中文语言包，确认并重启游戏后切换语言。
- 保留 Steam 成就统计与解锁逻辑，不改变任务条件、战斗、奖励或存档。
- 安装前校验版本并备份，支持卸载、重复安装及安装失败时回滚。

当前版本已经经过游戏显示实测，但尚未完成整个游戏流程的逐项测试。欢迎提交显示错误、漏译或译文问题。

## 卸载与备份

退出游戏后运行 **Uninstall.bat**。备份保存在游戏目录的 `.srhd-zh-backup`，请勿删除。

卸载还原原文件；如果安装后调整了其他模组选择，会保留这些选择。若 Steam 更新、文件验证或其他补丁已修改安装文件，卸载会停止，避免覆盖新版游戏。此时可使用 Steam 文件验证恢复原版，并在模组菜单中停用中文语言包。

已安装旧覆盖式汉化的玩家，请先恢复原版文件。德语/西班牙语语言包与中文互斥；其他第三方模组尚未逐一测试兼容性。

## 仓库内容

| 路径 | 内容 |
| --- | --- |
| `package/` | BAT 安装入口、PowerShell 安装器、版本清单、中文资源和程序增量补丁 |
| `translations/` | 校对后的译文参考汇总与去重字符清单 |
| `tools/build_release.py` | 校验资源并生成分发 ZIP |
| `tools/test_installer.py` | 从合法原版目录复制测试文件，在临时目录验证安装和卸载 |
| `docs/DEVELOPMENT.md` | 构建方法、测试和资源说明 |

普通玩家只需下载 Releases 中的 ZIP。参与修改安装器、重新打包的人需要 Python 3.10 或更高版本。
